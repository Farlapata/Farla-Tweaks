# Farla Tweaks Roadmap

## Product goal

Ship a Windows performance companion that understands the user's PC, builds a compatible optimization plan, applies only reviewed changes, proves what changed, and can undo those changes.

Every feature must move that goal forward.

## Milestone 0.1: Foundation

- [x] Windows WPF application shell
- [x] Frameless fixed-size window
- [x] Separate Core library
- [x] Structured tweak model
- [x] Compatibility engine
- [x] Registry snapshot and rollback foundation
- [x] Windows system profile detection
- [x] Starter tweak catalog
- [x] Windows CI build pipeline
- [ ] First successful downloadable Windows build

## Milestone 0.2: First usable flow

- [ ] Minimal dashboard with real system state
- [ ] Setup Wizard with real profile collection
- [ ] Recommendation plan generated from the tweak database
- [ ] Review screen explaining every recommendation
- [ ] One safe tweak with apply + verify + revert
- [ ] Persist optimization history locally

## Milestone 0.3: PC health

- [ ] Windows integrity checks
- [ ] Storage and startup checks
- [ ] Driver/device health
- [ ] Explainable health summary

## Milestone 0.4: Fortnite

- [ ] Fortnite profile
- [ ] Session detection
- [ ] FPS/frame-time monitoring
- [ ] Session history

## Milestone 0.5: Copilot

- [ ] Event detection
- [ ] Investigation rules
- [ ] Safe runtime interventions
- [ ] Keep/revert decisions based on measurements

## Later

Accounts, licensing, cloud sync, Pro services, creator profiles, affiliate program, and marketing are deliberately postponed until the local product is useful and reliable.
