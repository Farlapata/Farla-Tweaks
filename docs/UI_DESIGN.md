# Farla Tweaks UI Direction

## Window

Farla uses a custom frameless WPF window. The standard Windows title bar is intentionally removed to create a controlled, premium application surface.

- Fixed 1180x760 viewport for the initial release.
- No maximize or user resizing.
- Custom minimize and close controls.
- Entire chrome area can drag the window.
- Rounded outer shell with a very subtle border.

## Visual language

The interface is intentionally restrained:

- Near-black background.
- Dark charcoal surfaces.
- White primary typography.
- Muted gray secondary typography.
- A desaturated Farla accent used sparingly for active states, status indicators and important actions.
- No RGB gamer aesthetic, excessive glow or dense iconography.

## Dashboard hierarchy

1. Time-aware personalized greeting.
2. Farla Score.
3. Current primary game summary.
4. Farla Copilot state.
5. Contextual recommendation.

The dashboard should feel calm when the system is healthy. It must not invent warnings or fill space with unnecessary metrics.

## Navigation

Top navigation is preferred over a persistent sidebar:

- Overview
- Optimize
- Games
- Monitor
- History
- Settings

## Product feel

The application should feel like a premium desktop utility rather than a registry editor. The database and tweak complexity remain behind the interface. Users should primarily interact with goals, recommendations, diagnostics and results.
