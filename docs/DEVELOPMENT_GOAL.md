# Farla Tweaks Development Goal

## Product goal

Build a clean Windows performance companion that understands the user's PC, recommends compatible and explainable changes, safely applies them, verifies the result, and can reverse every supported change.

## Current milestone

The current milestone is a minimal, launchable Windows shell. The build must be green and produce a self-contained Windows x64 test package before the next visible UI layer is added.

## Development rule

Keep each milestone small enough to build and test. Do not add new feature layers while the current milestone is broken.
